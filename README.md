# BizInsight 📊

Instant, privacy-first business analytics right in your browser.

BizInsight is a lightweight, single-page application that turns your raw sales data (CSV or Excel) into an actionable business dashboard in seconds. Because it runs entirely client-side, your sensitive business data never leaves your computer.

## ✨ Features

* 🔒 **100% Privacy-First:** All data parsing and calculation happens locally in your browser. No data is ever uploaded to a server or cloud database.
* 🚀 **Instant Dashboards:** Automatically calculates critical KPIs like Revenue, Orders, Average Order Value (AOV), and Profit Margins.
* 📈 **Visual Analytics:** Generates dynamic charts for monthly trends, top products, city performance, and category breakdowns.
* 🤖 **Automated Insights:** Built-in logic analyzes your data to provide actionable observations and recommendations.
* 💬 **Ask Your Data:** An interactive Q&A interface that lets you ask plain-text questions about your sales.
* 📄 **One-Click Reports:** Generates a clean, copy-pasteable text report to share with your team.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, React (embedded)
* **Architecture:** Zero-dependency, single-file deployment. No build steps or Node.js required.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Drag and drop your `.csv` or `.xlsx` sales data file.
4. Explore your dashboard!
   
Live link - https://clever-churros-cf417e.netlify.app
